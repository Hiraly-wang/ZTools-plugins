# Changelog

## 1.1.0 - 2026-09-30

### 修复

- **重启管理器兜底检测完全失效**：`RmGetList` 的 `pnProcInfoNeeded`(out) 与 `pnProcInfo`(ref) 传入了同一个变量，计数被写回清零，导致分配 0 字节缓冲区、永远查不到占用者；异常还被空 `catch` 吞掉，所以一直静默失败。现在两者使用不同变量，失败会输出到 stderr 并记入运行记录。
- **一个文件被多个进程占用时漏报**：witr 匹配到多个目标时退出码为 4，输出的是一份人类可读列表（不是 JSON），此前被当作"无占用者"。现在会解析出全部 PID，并逐个用 `witr --pid` 补全启动链。
- **重启管理器结构体越界写内存**：`RM_PROCESS_INFO` 按 Ansi 计算大小，而 `RmGetList` 按 `WCHAR[256]/WCHAR[64]` 写入，缓冲区被写穿导致 PowerShell 宿主堆损坏（`0xC0000374`；1 个占用者侥幸不崩，2 个以上必崩）。结构体解析改到 C# 内完成，并显式标注 `CharSet.Unicode`。
- **路径特殊字符**：生成的 PowerShell 脚本改为单引号字面量并转义 `'`，路径中含 `$`、反引号、双引号时不再被当成变量或破坏脚本（此前可造成脚本错误甚至命令注入）。

### 新增

- **结束进程后闭环验证**：结束占用进程后轮询探测（约 1.8s）文件能否重新独占打开，只有确认解除才提示成功；仍被占用时明确提示"可能还有其他程序或系统服务在访问"，并刷新剩余占用者列表。端口检测同样会复查端口是否释放。
- **一键结束全部占用进程**（文件与端口）并统一验证结果。
- **占用状态四态探测**：被占用 / 可独占打开 / 文件夹 / 路径不存在。文件夹被占用（很常见的工作目录占用）会给出可执行的排查建议，不再只显示"无法确认锁定状态"。
- 权限不足与文件被占用分别提示，不再混为一谈、不再误入"查找占用进程"流程。

### 改进

- 前端提示改为**成功 / 提示 / 注意 / 错误**四级提示条，全部口语化文案：不再出现"退出码"、"engine="、"PID xxx 仍然存活"等调试字眼；需要排查时可展开底部"运行记录"。
- 进程卡片文案中文化：`Why It Exists` → "它是怎么跑起来的"、`Source` → "来源"、`Working Dir` → "工作目录"、`kill` → "结束进程"。
- 进程卡片展示 Windows 服务短名，并提示"直接结束可能触发服务自动重启，建议先停止该服务"。
- 占用者名称解析为真实进程名（此前重启管理器可能只给出单个字母，如 `W`）。
- 新增 preload 接口与文案的回归测试：重启管理器检测、双占用者端到端、闭环验证、占用状态探测、提示文案不含调试字眼、preload 暴露的接口齐全（75 个用例全绿）。测试串行执行，并改为"等占用真的建立"再断言，消除竞态导致的偶发失败。
- witr 仍为可选依赖：首次运行时自动释放/下载，不可用时由 Windows 重启管理器接管检测，功能不受影响。

## 1.0.0 - 2026-07-13

- 初次发布，将插件提交至 ZTools 插件仓库。
- 实现 Windows 文件占用检测与进程结束功能，支持文件和目录拖入。
- 增加文件删除/粉碎、端口占用查询及对应操作页面。
- 完善中文路径、权限与失败提示，修复 PowerShell 脚本和检测结果解析问题。
- 统一为 Windows 专用实现，完善发布时所需工具与依赖。
